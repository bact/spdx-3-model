# enabledByDefault

## Summary

Indicates whether a software artifact or a software agent is enabled by
default.

## Description

Indicates whether a software artifact or a software agent is in an operational
state upon installation, deployment, or invocation.

If `true`, the software artifact or the software agent is enabled by default
and will perform its intended function unless explicitly disabled.
