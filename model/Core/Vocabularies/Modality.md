# Modality

## Summary

Fundamental data or sensory type that a software artifact or agent accepts or produces.

## Description

Classifies the sensory or representational form of data that a software
artifact or agent processes as input or emits as output. Multiple values may be
declared when more than one form is used.

## Metadata

- name: Modality

## Entries

- text: Natural language or other character-based text.
- image: Still images.
- audio: Sound, including speech and music.
- video: Moving images, with or without sound.
- structuredData: Records with a defined structure, such as tables or key-value data.
- other: Any other modality not listed.
