# extensionDefinition

## Summary

Declares an extension used in the SpdxDocument.

## Description

Lists the extensions whose classes or properties are used in the
SpdxDocument, so that consumers and validators can find and verify their
definitions.

Declaring an extension is optional. An SpdxDocument may use an extension
without declaring it.
