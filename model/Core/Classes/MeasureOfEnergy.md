# MeasureOfEnergy

## Summary

The measure of energy expressed using a QUDT unit.

## Description

MeasureOfEnergy is a concrete `UnitOfMeasure` subclass for representing an
amount of energy using the standard QUDT unit encoding in `unitQUDT` and the
numeric `quantity` value.

- name: MeasureOfEnergy
- SubclassOf: UnitOfMeasure
- Instantiability: Concrete
